# Licensing

> **Decision pending.** No license has been chosen or applied to this
> repository yet. This document records the decision as outstanding; it is not
> a license grant.

## Status

There is currently no `LICENSE` file. The project does not yet have a declared
license. Until a decision is made and a `LICENSE` file is added, the code
remains under default copyright and should be treated as "all rights reserved".

## Considerations before choosing

1. **JasperReports compatibility.** JasperReports / Jaspersoft tooling has its
   own license terms. Verifying compatibility of intended behavior and any
   reference tooling against the chosen license is required.
2. **Third-party dependencies.** Every future dependency's license must be
   reviewed for compatibility with the project license and with each other. See
   the [dependency policy](DEPENDENCY_POLICY.md) for the review process.
3. **Distribution model.** Whether the engine is embedded in applications,
   distributed as a binary, or offered as a service may influence the choice.
4. **Contribution terms.** `CONTRIBUTING.md` currently does not require a
   contributor license agreement; this may need to change alongside the
   licensing decision.

## Next step

Choose a license deliberately and, as part of that change:

- add a `LICENSE` file at the repository root,
- update this document to describe the chosen license,
- review dependency licenses,
- update `README.md` and any package metadata that references licensing.

Do not silently select a license.
